# USB Display: Android-планшет или телефон как второй монитор по USB

Подключаете устройство кабелем к ПК с Windows, и оно становится настоящим вторым монитором. Окна перетаскиваются, рабочий стол расширяется, работает управление касаниями. Приложение для Android встроено в программу для ПК и ставится на устройство само.

## Установка

1. Скачайте `USBDisplay-v2.0.N.zip` из раздела **Releases** этого репозитория. Распакуйте и запустите `USBDisplay.exe`. Если SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в любом случае».
2. Один раз установите драйвер виртуального монитора: нажмите на уведомление или выберите пункт в меню значка в трее и подтвердите запрос Windows.
3. Один раз включите на устройстве **«Отладку по USB»**: меню значка → «Как подготовить телефон…».
4. Подключите кабель и нажмите «Разрешить» на устройстве. Программа сама установит приложение USB Display и запустит его.

Дальше достаточно подключить кабель.

## Как это устроено

```
ПК (Windows)                                               Android
────────────                                               ───────
Виртуальный монитор (Parsec VDD) — разрешение подбирается
пиксель в пиксель под экран устройства
   │ Desktop Duplication: кадр остаётся в видеопамяти
   ▼
Аппаратный кодировщик той же видеокарты, где монитор
(Intel Quick Sync / NVIDIA NVENC / AMD AMF), H.264 или H.265
   │ кадр уходит сразу, как только закодирован
   ▼
TCP ──────── adb reverse по USB-кабелю ────────►  MediaCodec (аппаратный декодер,
                                                   low-latency) → SurfaceView
SendInput (мышь) ◄──── касания, жесты, мышь ◄────  без браузера и лишних копий
```

## Что сделано для качества

- **Разрешение пиксель в пиксель, без растягивания.** Для экрана 2000×1200 выбирается 1920×1200, и картинка выводится 1:1. Масштаб интерфейса настраивается средствами Windows (меню → «Масштаб и расположение мониторов…»), а не снижением разрешения.
- **Высокий битрейт:** по USB передаётся 25–60 Мбит/с. Есть три ступени качества и выбор H.264 или H.265.
- **Без «пульсации» текста.** Ключевой кадр отправляется раз в 30 с, а не каждые 2 с. После сбоя устройство само запрашивает свежий ключевой кадр.

## Что сделано для минимальной задержки

- **Нативное приложение вместо браузера:** аппаратный декодер выводит кадр прямо на поверхность экрана, в режиме low-latency и с приоритетом реального времени.
- **Отображение:** если готово несколько кадров, показывается только последний. Экран устройства переключается на максимальную частоту (90/120/144 Гц, если поддерживается).
- **Кодирование:** без B-кадров и lookahead. Кодировщик берётся у той видеокарты, к которой подключён монитор, поэтому кадры не копируются между видеокартами.
- **Отправка кадра:** кадр уходит сразу. Длину кадра даёт формат FLV, ждать начала следующего не нужно.
- **Транспорт:** TCP без алгоритма Нейгла, повышенный приоритет процессов.

Касание тремя пальцами показывает статистику: кадры/с, битрейт, пинг, время декодирования, декодер.

## Управление

| Жест | Действие |
|---|---|
| Касание | щелчок |
| Удержание | правая кнопка |
| Провести пальцем | перетаскивание (окна, выделение) |
| Два пальца | прокрутка |
| Касание двумя пальцами | правая кнопка |
| Три пальца | статистика |

Мышь, подключённая к устройству по OTG или Bluetooth, тоже работает.

## Если что-то не так

- **Журнал:** меню значка → «Открыть журнал» (`%LOCALAPPDATA%\USBDisplay\usbdisplay.log`).
- **Приложение не установилось.** На Xiaomi и некоторых других устройствах включите «Установка через USB» в настройках для разработчиков, либо установите `USBDisplay.apk` из релиза вручную. Пока приложения нет, программа показывает экран через браузер.
- **Сбросить настройки:** удалите `%LOCALAPPDATA%\USBDisplay\config.json`.

## Сборка

Всё собирается автоматически на GitHub Actions при каждом push в `main` (файл `.github/workflows/build.yml`). Результат — релиз с `USBDisplay.exe`, внутри которого уже есть APK.

- `android/` — приложение (Java, без сторонних библиотек), собирается командой `./gradlew assembleRelease`.
- `pc/` — программа для Windows (Go, только стандартная библиотека): `go build -ldflags "-H windowsgui" .`

APK подписан ключом `android/app/usbdisplay.keystore`. Он лежит в репозитории, чтобы обновления ставились поверх. Ключ нужен только для домашней установки через USB.
